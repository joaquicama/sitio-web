sitio web de prueba

Lisboa Barbería

 Descripción del proyecto

**Lisboa Barbería** es un sitio web creado para presentar una barbería de estilo tradicional y moderno.

La página permite a los visitantes conocer los diferentes servicios disponibles, consultar sus precios, conocer al equipo de trabajo, ver una galería de cortes y solicitar un turno.

El objetivo principal del proyecto es crear una página web **moderna, atractiva y fácil de utilizar**, que sirva como presentación digital de la barbería.

 ¿De qué trata?

El sitio web representa a **Lisboa Barbería**, una barbería enfocada en cortes clásicos y modernos, cuidado de la barba y diferentes servicios de estética masculina.

La página presenta la barbería como un lugar donde se busca combinar:

-  Cortes clásicos y modernos
-  Perfilado y cuidado de barba
-  Combos premium
-  Cortes para menores
-  Color y camuflaje
- Atención personalizada
- Reserva de turnos

 Secciones de la página

El sitio está dividido en diferentes secciones para facilitar la navegación:

 **Inicio** → Presentación principal de la barbería.
-**Servicios** → Información sobre los servicios y precios.
 **Nosotros** → Historia y características de la barbería.
 **Galería** → Muestra diferentes estilos y trabajos.
 **Equipo** → Presentación de los barberos.
-*Reservar turno** → Formulario para solicitar un turno.

---

Tecnologías utilizadas

El proyecto está desarrollado utilizando tecnologías básicas de desarrollo web:

- **HTML5** → Para crear la estructura y contenido de la página.
- **CSS3** → Para el diseño, colores, tamaños, distribución y apariencia.
- **JavaScript** → Para agregar interactividad y funcionalidades al sitio.
